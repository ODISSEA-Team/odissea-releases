# ODISSEA

**Scientific simulation, spatial analysis, and environmental modelling.**

ODISSEA is a desktop application that brings together geographical data, environmental conditions, scientific simulations, and results analysis in one interface. It supports the exploration of complex landscapes and island environments through interactive maps and configurable simulation scenarios.

The application provides tools for map preparation and editing, island and terrain metrics, environmental data such as currents and water temperature, and multiple scientific models. Specialized analyses include PDZ, BRSD, and RBRSD workflows. Simulation outputs can be explored through maps, charts, tables, and exportable results.

ODISSEA is designed to support scientific research and exploratory analysis by making it easier to configure scenarios, examine model behaviour, compare results, and document findings.
